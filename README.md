## Experience

**Project Associate (Research)**  
KLE Technological University, Hubli, India  
Dec 2023 – May 2024 (SERB-funded research)  

- **Plant-AT Model:** Designed a hybrid attention model for real-time plant disease detection on Jetson AGX Orin. Integrated Inverted Residual Blocks with LG-Attention combining Separable Self-Attention and Neighborhood Attention, reducing attention complexity from O(n²) to O(n). The model (8.8M parameters) achieved 99% accuracy on PlantVillage and outperformed standard benchmarks by 5–7%.  
- **Plant-GAT Model:** Developed a Multi-scale Attention GAN that fuses Wavelet-guided latent encoding (via DWT) and diffusion-based refinement. Achieved SSIM = 0.92 and FID = 24.5, with 15% improvement in convergence and visual quality over baseline GANs.

## Academic Projects

**Project Intern**  
Center for Intelligent Mobility, KLE Tech  
Jun 2022 – Jun 2023  

- **Depth Completion via Sensor Fusion:** Fused sparse LiDAR and dense RGB using ResNet-50 and Residual Up-Projection decoding. Achieved RMSE = 0.203m and REL = 0.040 on NYUDepthV2.  
- **Lane Keeping Assistance with IoT & Deep Learning:** Designed real-time LKA system using CNNs and Kalman filtering, achieving 98% lane detection accuracy with 100ms latency in complex urban environments.  
- **Real-Time 3D LiDAR SLAM:** Proposed a novel radial encoding method for LiDAR point clouds, combined with Lie algebra-based optimization and loop closure using Scan Context + ICP. Reduced translation error by 71% and achieved inference at 21ms per frame.
